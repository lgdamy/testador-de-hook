# Webhook Tester

Aplicação destinada a **testar e validar integrações baseadas em webhooks**, facilitando o desenvolvimento e a homologação de integrações com parceiros.

## Objetivo

O projeto foi criado para **simplificar a integração com parceiros**, permitindo receber, visualizar e testar requisições de webhook de forma rápida e prática.

## Acesso

A aplicação está disponível em:

**https://webhooktester.ddns.net**

## Principais características

* Recebimento de webhooks;
* Visualização das requisições recebidas;
* Facilidade para testar integrações com parceiros externos;
* Ambiente simples para desenvolvimento e homologação;
* Acesso público para facilitar testes de integração.

## Fluxo

```text
Parceiro externo
       │
       │ Webhook
       ▼
Webhook Tester
       │
       ▼
Visualização da requisição
```
